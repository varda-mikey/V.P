# V-POINTS

Clean mobile-first Varda employee performance application.

## Architecture
- GitHub Pages: frontend hosting
- Supabase: database, authentication and storage
- No ChatGPT runtime dependency

## Core rules
- Employee baseline: 100 points
- No self-merit
- Regional actions requiring merit approval are escalated to the authorized higher role
- National/executive roles retain employee profiles and appraisal history
- Evidence should be compressed client-side before upload

## Planned modules
Missions, My Team, Memo Hub, Training, FSQA Audit, Policy Library, Rewards, Attendance, Forms, Schedule Maker, leader engagement/activity metrics, guidelines/privacy information.

The previous VPOINTS repository remains separate and untouched as a backup/reference while this clean build is developed.
